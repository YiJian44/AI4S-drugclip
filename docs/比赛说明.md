第四届世界科学智能大赛——AI4S智能体CNS挑战赛
任务1：DrugClip高通量虚拟筛选优化智能体
赛事背景
在数据驱动的科学发现时代，Cell、Nature、Science（CNS）等顶级期刊不仅是前沿科学的殿堂，更已成为 AI for Science (AI4S) 探索的核心阵地。从蛋白质结构的精准预测到复杂生命系统的模拟，AI 正在重塑基础科学的边界。然而，在传统的科研流程中，AI 往往只作为静态的辅助工具，其能力不仅高度依赖人类科学家的手动调参，且面对 CNS 级别的宏大科学问题时，传统的“人力主导”模式在处理超大规模、高维数据时已触及认知与效率的瓶颈。

自主科研 Agent 的兴起，预示着科研范式的下一次跃迁。本次挑战赛旨在探索 AI 在顶级科学研究中的极限潜力：我们不仅挑战让 Agent 自动化地复现与极致优化 CNS 上的前沿模型，更期望它们能展现出前所未有的自主创新能力，去推理、设计并尝试解决具有 CNS 影响力的重大科学问题。 在这里，AI 将完成从“被设计的模型”到“能解决世界级难题的 AI 科学家”的华丽蜕变。

Agent 核心任务：构建科研闭环能力
为了应对 CNS 级别的挑战，Agent 必须具备以下四个核心阶段的自动化能力：

文献解析与逻辑解构： Agent 需具备深度的多模态阅读能力，能够自主研读顶刊论文及其配套源代码，精准理清底层数学公式、数据流向、核心算法逻辑以及科学问题的本质。
瓶颈诊断与假设提出： 面对既有模型或未解问题，Agent 需通过分析原始训练日志（Log）或科学数据，敏锐识别在计算效率、模型泛化能力或理论覆盖面上的痛点，并自主提出具有科学依据的优化假设或求解策略。
自主设计与代码演进： 突破“黑盒调用”的限制，Agent 需根据其诊断结果和科学假设，制定具体的工程方案（如：重构网络结构、设计全新的损失函数或引入外部科学工具），并直接编写/修改高质量代码来实现这些创新。
实验验证与科学迭代： Agent 需在测试环境中自主运行干实验，管理多分支的实验版本。通过对实验结果的高效分析，判断当前策略的有效性，并据此调整方向，完成自我进化的科学迭代。
赛题介绍
蛋白结构预测（如 AlphaFold）让我们第一次有机会在“全基因组尺度”上做药物发现：面对上万蛋白靶点与海量化合物库，传统 docking 需要巨量算力，难以扩展到 genome-wide 规模。Science 论文 Deep contrastive learning enables genome-wide virtual screening 提出 ​DrugCLIP​：用深度对比学习​把“口袋—分子”对映射到同一向量空间，通过向量相似度实现超快筛选，相比 docking 在速度上可实现数量级提升，同时在多个基准（如 DUD-E、LIT-PCBA）上保持较强早期富集表现。

本赛题关注一个更进一步的问题：

能否让科学智能体​（agent）自动执行“数据准备—训练/微调—评测—​超参/策略迭代—结果汇报”的闭环，系统性优化 DrugCLIP 的虚拟筛选表现与效率？

参赛者需要构建一个 agent（可调用工具/脚本/检索/训练等），自动做出提升 EF1%等指标的优化决策，并输出可复现的结果与日志。

背景知识
本赛题涉及的核心概念包括：

虚拟筛选（Virtual Screening） 给定靶点（蛋白口袋）与候选小分子库，输出“最可能结合”的 top-K 分子列表。实际工作往往只验证排名最靠前的极小比例，因此评估更关注“早期富集”。
对比学习检索式筛选（Contrastive Retrieval） DrugCLIP 将口袋和分子分别编码为向量，通过相似度（如 cosine/dot product）快速排序；相比逐分子 docking，它更像“向量检索”，适合大规模扩展。
评测指标：EF1%（Enrichment Factor @ top 1%） 衡量模型在排名前 1% 的候选里，相比随机抽样富集到活性分子的倍数；更贴近“只测 top 少量化合物”的现实场景。
科学智能体​（Agent）自动化优化
你的 agent 需要自动探索：
训练/微调策略（冻结层、学习率、batch、负采样等）
数据处理/增强（构象采样、去冗余、采样比例等）
推理/排序策略（多模型融合、重排序、top-K 选择策略）
并给出清晰日志证明优化过程是自动执行的，而不是人工手调一次性提交。
比赛任务
给定若干个匿名靶点（target），每个靶点提供：

受体结构文件（receptor.pdb）
候选分子库（ligands.csv：ligand_id, smiles）
参赛者需要为每个靶点输出候选分子的​打分/排序​（score 越高表示越可能为活性），用于主指标：​Mean EF1%​评测。

1. 测试集范围
DUD-E：共 102 个任务，每个靶点 1 个任务。
LIT-PCBA：共 15 个任务，每个靶点 1 个任务。
总任务数：117
总配体数：2092260
说明：

DUD-E 任务来自对应靶点的测试配体集合。
LIT-PCBA 任务使用该 benchmark 的保留测试划分。
2. 目录结构
manifest.jsonl
全部任务索引，每行一个 JSON 对象。
tasks/<task_id>/task.json
单个任务的公开元信息。
tasks/<task_id>/ligands.csv
该任务的待排序配体列表。
tasks/<task_id>/receptors/
受体结构文件。
tasks/<task_id>/refs/
参考共晶配体，可用于口袋定位、对齐或定义 docking box。
3. 两类任务的含义
3.1 DUD-E
每个任务只有 1 个 receptor。
receptors/receptor.pdb 是受体结构。
refs/crystal_ligand.mol2 是该结构对应的共晶配体。
3.2 LIT-PCBA
每个任务可能有多个 receptor 结构。
receptors/*.mol2 是同一 target 的多个已知结构。
refs/*_ligand.mol2 是各结构对应的共晶配体。
选手可以使用单结构或多结构方法，但最终每个 ligand 只能输出 1 个分数。
4. ligands.csv 字段说明
公开版 ligands.csv 只保留以下字段：

ligand_id
本测试集内部唯一编号，提交时必须使用。
smiles
配体 SMILES。
5. 选手提交格式
选手最终需要提交一个压缩包：

result.zip
├── result.csv
└── result.log
​
其中 result.csv 为排序结果文件，格式如下：

task_id,ligand_id,score
dude_aa2ar,dude_aa2ar__L000001,12.53
dude_aa2ar,dude_aa2ar__L000002,1.42
litpcba_ADRB2,litpcba_ADRB2__L000001,3.88
​
其中 result.log 为运行日志，用于记录 agent 的主要自主优化过程，例如：

方案设计与迭代
训练或微调过程
推理、重排序与结构聚合过程
关键决策与中间结果
最终结果生成过程
要求：

每个 (task_id, ligand_id) 必须且只能出现一次。
所有任务必须覆盖完整。
score 越高，排序越靠前。
result.zip 中必须同时包含 result.csv 和 result.log
说明：

平台评测脚本按 result.zip 格式读取提交。
主办方会结合 result.log 分析选手的 agent 是否确实进行了自主优化。
如果日志显示方法并未真实进行自主优化，或存在违规使用测试集、直接恢复答案等行为，最终分数可能被置零。
